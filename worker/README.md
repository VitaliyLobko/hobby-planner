# Бот Хобі-плану (Cloudflare Worker)

Один файл `worker.js`, без збірки: вставляється в редактор Cloudflare.

## Що робить

- Нагадує про вікно дня одним повідомленням з усіма його справами: на початку вікна і за 30 хв до кінця — якщо ще не відмітив. Кнопки лишаються лише на найновішому повідомленні вікна; поки в вікні йде таймер — не смикає.
- Кнопки: одна відкрита справа — ▶ почав (таймер) · ✅ зробив · ◐ мінімум · ⏰ +30 хв · ↷ перенести · ✕ пропускаю. Кілька — рядок на справу: ✅ зробив · ▶/⏸ · ⋯ (мінімум, перенести, пропускаю), унизу ⏰ +30 хв на все вікно.
- Зранку (за 10 хв до першого вікна) — план дня, у кінці останнього вікна — підсумок.
- Команди: `/today`, `/week`, `/key` (ключ для застосунку), `/help`.
- Синхронізація: застосунок шле план на `/api/sync`, відмітки з бота повертаються в застосунок.
- Голосом чи текстом (потрібна прив'язка `AI`): голосове до хвилини розпізнає Whisper (`whisper-large-v3-turbo`, підказка — назви занять), фразу розбирає Llama 3.3 70B у JSON-режимі на дії: зробив (з хвилинами й темою), мінімум, пропускаю, почав/пауза таймера, заплануй, перенеси, прибери, вага, план на сьогодні, тиждень. Кілька дій в одній фразі. Модель лише пропонує — що змінити, вирішує код за правилами кнопок (вікно, що минуло, дубль заняття у вікні тощо). Зробив те, чого не було в плані, — додається зробленим у вікно, що йде. У підсумку — почуте й що зроблено, «↩️ Скасувати» повертає останню фразу. Без прив'язки `AI` текст, як і раніше, — довідка.
- Вага (для застосунку [Weight Log](https://vitaliylobko.github.io/weight-log/)): о часі нагадування з «Ваги» — «⚖️ Час зважитись» (⏰ +30 хв · сьогодні без зважування), через годину — ще раз, якщо ваги немає; пізніше 3 год не нагадує. Повідомлення-число (`82,4`, `82.4 кг`, `82,4 після свята`, 30–250 кг) — вага за сьогодні, у відповідь різниця з минулим разом. «Вага» обмінюється записами через `/api/weights` (тим самим ключем), на паузі нагадування теж мовчить.
- «📌 Не забудь» — нагадування окремо від хобі (разове, щодня, у дні тижня, у числа місяця; числа, якого в місяці немає, — в останній день), з вікном «з — до». Приходять на початку вікна, далі раз на годину й останнє за 15 хв до кінця — поки не «✅ Зроблено»; «⏰ +30 хв» відкладає. На паузі теж приходять. Відмітка в застосунку прибирає кнопки в чаті. Голосом: «нагадай 1 і 15 числа з 6 до 9 згенерувати код Нової пошти». У `/today` і ранковому плані — блоком «Не забудь».
- Вихідні дні — з налаштувань застосунку; зміна розкладу вікон переносить уже заплановані справи на нові години.
- Тихі години (meta `quiet`, з застосунку): tick нічого не шле; що настало за цей час, приходить одним повідомленням після них.
- Разове «Не забудь» — кнопка «➡️ Завтра» (переносить дату, застосунок отримує при синхронізації).
- Постійний розклад заняття (`repeat` з застосунку: дні, вікно, версія `v`): при синхронізації й раз на день справи на 7 днів уперед зі сталим ключем `r<v>-<рррммдд>-<заняття>`; прибрана лишається в базі як deleted — назад не повертається; зміна розкладу прибирає незачеплені справи старого. Логіка — як `repeatPlan` у `js/model.js`.
- Таймер дійшов до звичних хвилин заняття — «⏱ … Зараховуємо?» (✅ зробив · ⏸ пауза · ⏰ ще 10 хв), один раз; стан у `rem_state` з ключем `t:<id>`.
- Після вечірнього підсумку — «🌙 План на завтра»: «Як минулого <дня>», «Як сьогодні», шаблони (до трьох) — лише ті, що щось додадуть; «↩️ Скасувати». Завтра пауза чи додавати нічого — не шле.
- `/api/restore` (той самий ключ) — усе для нового телефона: заняття, увесь план, нагадування, вікна, паузи, тихі години, шаблони (шаблони бот лише зберігає).

## Налаштування

1. **D1**: Storage & databases → D1 → Create → назва `hobby`.
2. **Worker**: Workers & Pages → Create → Worker → назва `hobby-bot` → Deploy → Edit code → вставити `worker.js` → Deploy.
3. **Прив'язка бази**: Worker → Settings → Bindings → Add → D1 database → змінна `DB`, база `hobby`.
4. **Токен**: Worker → Settings → Variables and Secrets → Add → тип **Secret**, назва `BOT_TOKEN`, значення — токен від @BotFather.
5. **Cron**: Worker → Settings → Trigger events → Add → Cron → `* * * * *`.
6. Відкрити `https://hobby-bot.<піддомен>.workers.dev/` — Worker сам ставить вебхук і команди.
7. У Telegram боту: `/start` (прив'язка до себе), потім `/key`.
8. Застосунок → Налаштування → Telegram-бот: адреса Worker і ключ → «Зберегти й синхронізувати».
9. **Голос** (необов'язково): Worker → Settings → Bindings → Add → Workers AI → змінна `AI`.

Таблиці в D1 Worker створює сам. Секрет вебхука виводиться з токена, окремо його задавати не треба.

## Безпека

- Власник — перший, хто написав `/start`; усі інші чати бот ігнорує. Перевизначити — змінна `OWNER_ID`.
- Запити Telegram перевіряються заголовком `X-Telegram-Bot-Api-Secret-Token`.
- Ключ застосунку зберігається лише як SHA-256; `/key` видає новий і скасовує старий.
- CORS — лише для `https://vitaliylobko.github.io` і локальних `http://127.0.0.1:8093` (Хобі-план), `:8094` («Вага»).

## Часовий пояс

`Europe/Kyiv` (змінна `TZ`, якщо треба інший). Перехід на літній/зимовий час враховано.
